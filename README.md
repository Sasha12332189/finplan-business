# finplan Business

Учёт, отчёты и налоги для малого бизнеса прямо в Telegram: бот `@finplan_business_bot` + Mini App.
Пишешь боту «продал 3 торта по 450» — и всё посчитано: прибыль, налог, отчёт, Excel.

Отдельный проект от личного finplan: свой репозиторий, свой сервис на Railway, своя база PostgreSQL, свой бот.

**Стек:** FastAPI · aiogram 3 · SQLAlchemy async (PostgreSQL / SQLite) · Mini App на HTML/JS · openpyxl · reportlab · Claude API (`anthropic`) · cryptography.

## Что умеет

| Раздел | Что есть |
|---|---|
| Бот | онбординг (название, тип, группа ФОП, НДС), быстрый ввод `4500 продажа торт`, `-1200 мука`, `+15000 Иванов предоплата`, `продал 3 торта по 450`; кнопки «Отменить · Категория · Клиент»; `/today /week /month /tax /invoice /debts /report /team /ai /premium /paysupport /terms /app` |
| Автосообщения | итог дня в 21:00 (по желанию), недельный отчёт в понедельник + вывод ИИ, отчёт 1-го числа + Excel (Pro), налоги за 7 и 1 день до срока, лимит дохода ФОП 70/90/100 %, просроченные счета с кнопкой «Напомнить клиенту», кассовый разрыв, регулярные операции |
| Mini App | Главная (период, выручка/расходы/прибыль/маржа со сравнением, график, налоги, лимит ФОП, «Нужно внимание», ИИ, счета и кассы), Операции (поиск и фильтры), Отчёты (P&L, денежный поток, категории, клиенты, проекты, сотрудники, сравнение, Excel/PDF/CSV в чат), Документы (счета, долги, налоги по кварталам, книга доходов), Ещё (подписка, бизнес, счета, банки, команда, категории, проекты, контрагенты, регулярные, склад, автосообщения, язык uk/ru/en, тема) |
| Налоги | единый налог 1–3 группы, ЕСВ, военный сбор, сроки, лимиты дохода — все ставки в [`app/tax_rates.py`](app/tax_rates.py) (таблица «год → значения») |
| Отчёты | Excel: 7 листов (сводка, операции, по категориям, по месяцам, клиенты, налоги, книга учёта доходов), живые формулы `SUMIF`/`SUM`, графики, фирменные цвета; PDF-отчёт; PDF-счёт; CSV (бесплатно). Файлы приходят в чат бота |
| Подписка | Telegram Stars: месячная нативная подписка (автопродление) и годовая разовая оплата, триал 14 дней Pro на каждый новый бизнес, все проверки тарифа на сервере |
| ИИ | Claude с tool use: записи из свободного текста, фото чеков, голосовые; вопросы по данным; выводы в отчётах. Ничего не пишется без кнопки «✅ Записать» |
| Банки | monobank (личный токен, хранится зашифрованным), ПриватБанк Автоклиент |
| Команда | роли owner / admin / staff / accountant, одноразовые приглашения на 2 дня, склад с себестоимостью продаж, реферальная программа (+30 дней Pro) |

## Переменные окружения

| Переменная | Обязательна | Зачем |
|---|---|---|
| `BUSINESS_BOT_TOKEN` | да | токен бота от @BotFather (принимается и `BOT_TOKEN`) |
| `DATABASE_URL` | да на Railway | строка подключения PostgreSQL. `postgres://…` сам превращается в `postgresql+asyncpg://…`, `sslmode` убирается. Без неё используется SQLite, который **стирается при каждом деплое** |
| `PUBLIC_APP_URL` | желательно | публичный адрес сервиса, например `https://finplan-business.up.railway.app`. Если не задан, берётся `RAILWAY_PUBLIC_DOMAIN`. Нужен для вебхука и кнопки Mini App |
| `ANTHROPIC_API_KEY` | для ИИ | ключ Claude API. Без него ИИ-функции честно отвечают «не настроено» |
| `AI_MODEL` | нет | модель ассистента, по умолчанию `claude-opus-5-5` |
| `AI_MODEL_FAST` | нет | модель для коротких выводов в отчётах (например `claude-haiku-5-5`); пусто = `AI_MODEL` |
| `ENCRYPTION_KEY` | для банков | ключ шифрования банковских токенов. Лучше Fernet-ключ: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. **Не меняйте после подключения банков** — старые токены перестанут расшифровываться |
| `ADMIN_TELEGRAM_IDS` | нет | Telegram id через запятую: их бизнесы всегда на Team, им доступна команда `/refund <charge_id>` (возврат звёзд) |
| `SUPPORT_CONTACT` | желательно | контакт для `/paysupport`, например `@username` (Telegram требует поддержку платежей) |
| `TRANSCRIPTION_API_URL` | для голоса | любой OpenAI-совместимый `/audio/transcriptions`, например `https://api.openai.com/v1/audio/transcriptions` или `https://api.groq.com/openai/v1/audio/transcriptions` |
| `TRANSCRIPTION_API_KEY` | для голоса | ключ этого сервиса |
| `TRANSCRIPTION_MODEL` | нет | по умолчанию `whisper-1` (для Groq — `whisper-large-v3`) |
| `PERSONAL_APP_URL` | нет | ссылка на личный finplan (например `https://t.me/finplan_bot/app`) — в переключателе бизнесов появляется «Личное» |
| `BANK_SYNC_MINUTES` | нет | как часто тянуть выписку банка, по умолчанию 30 |
| `DEFAULT_TIMEZONE` | нет | по умолчанию `Europe/Kyiv` |
| `WEBAPP_AUTH_MAX_AGE_SECONDS` | нет | срок жизни initData, по умолчанию 86400 |
| `DEBUG`, `DEV_TELEGRAM_USER_ID` | только локально | вход без Telegram через заголовок `X-Dev-Telegram-User` или `?dev=<id>`. **Никогда не включайте `DEBUG` на Railway** |

Railway сам задаёт `PORT`, `RAILWAY_PUBLIC_DOMAIN`, `RAILWAY_ENVIRONMENT` — их трогать не нужно. Пример — [`.env.example`](.env.example).

## Деплой на Railway

1. **New Project → Deploy from GitHub repo** → `Sasha12332189/finplan-business`. Railway соберёт [`Dockerfile`](Dockerfile) (в нём ставятся шрифты DejaVu для кириллицы в PDF) и запустит `python start_railway.py` ([`railway.json`](railway.json), проверка здоровья `/health`).
2. В проекте **+ New → Database → PostgreSQL**. В сервисе приложения → **Variables** добавьте `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`.
3. **Settings → Networking → Generate Domain** — получите адрес вида `finplan-business-production.up.railway.app`.
4. Переменные: `BUSINESS_BOT_TOKEN`, `PUBLIC_APP_URL` (адрес из шага 3 с `https://`), `ANTHROPIC_API_KEY`, `ENCRYPTION_KEY`, `SUPPORT_CONTACT`, при желании `ADMIN_TELEGRAM_IDS`, `AI_MODEL_FAST`, `TRANSCRIPTION_*`, `PERSONAL_APP_URL`.
5. Дождитесь деплоя. При старте сервер сам ставит вебхук `PUBLIC_APP_URL/telegram/webhook` с секретом, команды бота и синюю кнопку Menu → Mini App. Таблицы создаются автоматически.
6. Платежи Telegram Stars отдельно включать не нужно. По желанию в @BotFather `/newapp` — ссылка вида `t.me/finplan_business_bot/app`.
7. Откройте бота → `/start`.

Любая точка входа поднимает веб-сервер: и `python start_railway.py`, и `python -m app.bot` (если задан `PORT`). Вебхук при остановке не удаляется — так бот не «замолкает» после редеплоя.

## Локальный запуск

```bash
python -m venv venv
venv/Scripts/pip install -r requirements.txt      # Linux/Mac: venv/bin/pip
# PowerShell: $env:DEBUG="true"   bash: export DEBUG=true
python -m scripts.seed_demo 1001                  # демо-бизнес «Торты Оли»
uvicorn app.main:app --port 8000
# http://localhost:8000/?dev=1001  (можно &theme=dark, &tab=reports)
```

Бот локально через long polling: `python -m app.bot` без `PORT` (удаляет вебхук — потом передеплойте сервис).

## Что проверено, а что нет

Проверено автотестами и вручную (локально на SQLite; экраны на ширине 390 px в светлой и тёмной теме): расчёты, API, роли и лимиты, Excel/PDF, логика подписки, импорт выписки monobank на примере ответа.

**Не проверено на реальных сервисах** (нужны настоящие ключи и аккаунты):
- реальные платежи Telegram Stars и автопродление — логика написана по Bot API и покрыта тестами, но живой оплаты не было;
- вызовы Claude API — тесты идут с подставным клиентом, реальный ключ не использовался (в том числе не проверено, что API принимает схемы инструментов со `strict: true`);
- monobank — формат по документации API, живым токеном не проверялся;
- ПриватБанк Автоклиент — названия полей ответа нужно сверить на реальном счёте;
- распознавание голоса — зависит от выбранного сервиса транскрипции;
- PostgreSQL — код переносимый (SQLAlchemy), но запускался только на SQLite;
- бот в Telegram — обработчики не запускались против живого Bot API.

**Налоги — справочно.** Ставки на 2025 и 2026 годы (на 2026: мин. зарплата 8 647 ₴, прожиточный минимум 3 328 ₴, ЕСВ 1 902,34 ₴/мес, военный сбор) нужно сверить с tax.gov.ua перед запуском и обновлять каждый год в `app/tax_rates.py`. Расчёт не заменяет бухгалтера.

## Открытые вопросы (решить владельцу)

- Название бота и домен; окончательные цены в Stars.
- Модель ИИ и лимиты: по умолчанию `claude-opus-5-5`; для экономии `AI_MODEL_FAST=claude-haiku-5-5` для выводов в отчётах.
- Связка с личным finplan сейчас — ссылка-переключатель (`PERSONAL_APP_URL`); единый аккаунт требует общей базы или API между проектами.
